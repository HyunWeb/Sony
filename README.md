## 📜 프로젝트 소개  
부트캠프에서 학습한 HTML, CSS, JavaScript, jQuery를 활용하여 팀 프로젝트로 진행한 소니 음향기기 홈페이지 리뉴얼입니다.  
소니의 기존 홈페이지는 여러 전자기기를 복합적으로 다루고 있었으나, 이번 프로젝트에서는 **소니 음향기기 사업**에 초점을 맞춘 전문 홈페이지를 제작하였습니다.

## 🛠️ 주요 기능 및 구현  

### 1. 🏠 메인 페이지  
- **주요 섹션**:  
  1. 인상적인 메인 화면  
  2. 베스트 셀링 3가지 제품 소개  
  3. 각 페이지로의 연결  

- **스크롤 애니메이션**:  
  - 스크롤 이벤트로 메인 화면에서 하단 섹션으로 자연스럽게 이동.  
  - `deltaY` 속성과 `scrollTop`을 활용하여 스크롤 방향과 위치를 감지, 페이지 전환 구현.  

### 2. 🏛️ 회사 연혁 페이지  
- **슬라이드쇼 구현**:  
  - 회사 제품들의 슬라이드쇼가 상단에 배치.  
  - 클릭-드래그를 통한 좌우 이동 지원, 드래그 방향에 따라 슬라이드 방식 변경.  

### 3. 💡 소니 기술력 페이지  
- **DOM 조작을 활용한 역동적인 페이지**:  
  - 스크롤 시 투명했던 콘텐츠가 하나씩 등장하며 강조 효과 구현.  

### 4. 🛒 장바구니 기능  
- **주요 기능**:  
  1. JSON 파일을 활용해 제품 정보 관리.  
  2. 사용자가 선택한 물건과 개수를 객체로 저장하고 배열에 추가.  
  3. 로컬 스토리지를 활용해 메인 페이지와 장바구니 페이지 간 데이터 공유.

## 🤝 협업 전략 및 문제 해결  

### 1. 🎨 디자인  
- **문제**: 팀원들의 디자인 경험 부족 및 프로그램 사용 어려움.  
- **해결**:  
  - 피그마(Figma)를 활용한 디자인 작업.  
  - 컨텐츠와 레이아웃을 구상한 후 피드백을 통해 최종 디자인 결정.  
  - 디자인 통일성을 유지하며 작업 분배.  

### 2. ⚙️ 협업 도구  
- **Git/GitHub 활용**:  
  - 브랜치 규칙 설정: 메인 브랜치로의 직접 푸시 금지, PR(Pull Request) 승인 절차 적용.  
  - 깃허브를 활용한 협업 환경 구성 및 코드 충돌 방지.  

### 3. 🗂️ 코드 중복 제거  
- **공통 요소 관리**:  
  - `reset.css`로 브라우저 기본 스타일 초기화.  
  - 버튼 스타일과 폰트를 별도 CSS 파일로 관리하여 중복 최소화.  
- **공통 HTML 요소 삽입**:  
  - `CreateElement`와 `fetch`를 활용해 네비게이션 바와 푸터를 동적으로 삽입.

## 🙇 아쉬운 점과 개선 방향  

### 1. 📱 반응형 디자인 미흡  
- **문제**: 데스크탑 기준으로 작업을 시작하여 모바일 환경에서 레이아웃이 깨지는 문제 발생.  
- **개선 방안**:  
  - 다음 프로젝트에서는 **모바일 우선 접근(Mobile-First Approach)**으로 작업을 시작하여 데스크탑 환경으로 확장.  
  - 불필요한 요소를 덜어내고 추가 작업만 진행하는 방식으로 반응형 작업을 개선.  

### 2. 📊 데이터 조작 부족  
- **문제**: 초기에는 DOM 조작에만 의존하여 JS의 자료구조 활용이 부족.  
- **개선**: JSON 데이터를 기반으로 다양한 데이터 조작 및 객체 관리를 활용.
