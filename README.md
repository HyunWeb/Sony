## 📜 프로젝트 소개  
부트캠프에서 학습한 HTML, CSS, JavaScript, jQuery를 활용하여 팀 프로젝트로 진행한 소니 음향기기 홈페이지 리뉴얼입니다.  
소니의 기존 홈페이지는 여러 전자기기를 복합적으로 다루고 있었으나, 이번 프로젝트에서는 **소니 음향기기 사업**에 초점을 맞춘 전문 홈페이지를 제작하였습니다.  

**🔹 나의 역할**  
- 프로젝트 **팀장**: 일정 조율 및 작업 분배  
- **메인 페이지 및 장바구니 페이지 개발**  
- **디자인 설계 및 UI/UX 기획 총괄**  
- **코드 리뷰 및 리팩토링**

## 💻 개인 구현 기능
### 1. 로컬스토리지 API를 활용한데이터 공유
- 새로고침에도 데이터가 유지되어 안정적인 데이터 구현이 가능해졌습니다.
### 2. JSON 파일을 활용한 데이터 구현
- 서버없이 데이터 관리와 구현을 할 수 있었으며, 개발 및 배포의 효율성을 높였습니다.
### 3.  ES6 모듈화를 활용한 동적 알림창 구현
- 코드의 재사용성을 높이고 개발 생산성을 향상시킬 수 있었습니다.
### 4.  fetch API를 활용한 HTML 컴포넌트 재사용
- Nav 요소를 한 번만 작성해 전체 페이지에서 관리할 수 있게 되었습니다.
